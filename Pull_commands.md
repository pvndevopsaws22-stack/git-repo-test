# 1. Basic Git Pull commands
## Pull changes from the current branch
git pull

## Pull from specific remote
git pull origin
Uses the origin remote and cureent branch's configured merge target

## Pull a specific branch
git pull origin main

## Pull using rebase
git pull --rebase

## Pull a specific branch using rebase
git pull --rebase origin main

## Pull with fast-forward only
git pull --ff-only
